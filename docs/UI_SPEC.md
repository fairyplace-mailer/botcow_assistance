# UI Спецификация (BotCow Code Assistant)

UI должен предоставлять удобный интерфейс для ассистента разработчика.

## Основные элементы UI

### 1. Главное окно чата
- История сообщений: пользователь → ассистент.
- Поддержка многоходовых диалогов.
- Ассистент отвечает с контекстом репозитория.

### 2. Загрузка файлов
Блок **"Upload"**:
- загрузить `.ts`, `.tsx`, `.json`, `.md`, `.yml`
- отправляется на backend `/api/logs` или `/api/github/commit`

### 3. Панель действий (слева или сверху)
Кнопки:
- **Create branch**
- **Commit file**
- **View file**
- **Create PR**
- **Run workflow**
- **Merge PR**

Это триггеры API-запросов.

### 4. Окно предпросмотра файлов
Показывает содержимое файла из GitHub:
- подсветка синтаксиса
- возможность изменить и отправить обратно через commit

### 5. Уведомления (toast)
- Принят/не принят запрос
- Ошибка GitHub
- Статус workflow

### 6. PWA-интеграция (обязательно)
- `manifest.json`
- `service-worker.js`
- Иконки
- Offline-страница
- Установка на устройство

### 7. Требования
- Next.js 16 / App Router
- статичность UI, все действия — через API Routes
- без сторонних UI-фреймворков, только Tailwind или чистый CSS
